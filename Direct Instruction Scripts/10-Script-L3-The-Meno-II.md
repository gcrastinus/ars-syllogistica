## 2. NEW MATERIAL (12 min) — two rules, then a two-minute preview

### 2A. The two Definition Rules and the counterexample hunt

**MODEL**

**Yesterday we asked: is this one answer, or a swarm? Today we test the answer.**

**A definition is one answer that says what a thing is.**

**A definition must do two jobs.**

(Write and leave up:)

```
RULE 1 — A definition must include every instance of the thing defined.
RULE 2 — A definition must exclude everything that is not the thing defined.
```

**Rule 1: A definition must include every instance of the thing defined.**

**Rule 2: A definition must exclude everything that is not the thing defined.**

**Rule 2 is how the definition shows how that kind differs from other, similar things.**

**We test a definition by hunting for a counterexample.**

**A counterexample is an instance left out — that breaks Rule 1 — or an outsider let in — that breaks Rule 2.**

**If Rule 1 breaks, say TOO NARROW, then name what was left out.**

**If Rule 2 breaks, say TOO WIDE, then name the outsider let in.**

**If both rules hold, say GOOD.**

**Listen. A dog is a black animal.** (pause) **White dogs are dogs, and they are left out. TOO NARROW — white dogs. That breaks Rule 1.**

**A dog is an animal.** (pause) **Cats are animals, and they get in. TOO WIDE — cats. That breaks Rule 2.**

**A triangle is a shape with three straight sides.** (pause) **Every triangle is in. Squares and circles stay out. GOOD.**

**Hear those three again. A dog is a black animal.** (pause) **TOO NARROW — white dogs.**

**A dog is an animal.** (pause) **TOO WIDE — cats.**

**A triangle is a shape with three straight sides.** (pause) **GOOD.**

**LEAD** (teacher joins the verdict and the named counterexample)

**A dog is a black animal.** (pause; Signal)
→ TOO NARROW — white dogs
(Accept: brown dogs / yellow dogs / any non-black dog. If they give only TOO NARROW: **Name what was left out.**)

**A dog is an animal.** (pause; Signal)
→ TOO WIDE — cats
(Accept: horses / birds / any non-dog animal.)

**A triangle is a shape with three straight sides.** (pause; Signal)
→ GOOD

**A chair is a red seat.** (pause; Signal)
→ TOO NARROW — blue chairs
(Accept: any non-red chair.)

**A chair is furniture.** (pause; Signal)
→ TOO WIDE — tables
(Accept: beds / desks / any non-chair furniture.)

**TEST** (students only; they must name the counterexample, not just the verdict)

**A shoe is a black covering for the foot.** (pause; Signal)
→ TOO NARROW — brown shoes
(Accept: any non-black shoe.)

**A shoe is clothing.** (pause; Signal)
→ TOO WIDE — hats
(Accept: shirts / coats / any non-shoe clothing.)

**A shoe is clothing for the foot.** (pause; Signal)
→ GOOD

**A bird is an animal with feathers.** (pause; Signal)
→ GOOD

**A fruit is a food.** (pause; Signal)
→ TOO WIDE — bread
(Accept: meat / soup / any non-fruit food.)

**A sister is an older girl in your family.** (pause; Signal)
→ TOO NARROW — younger sisters
(Accept: a twin sister / a baby sister.)

**A sister is a girl.** (pause; Signal)
→ TOO WIDE — a girl next door
(Accept: any girl who is not a sister.)

**A hammer is a red tool.** (pause; Signal)
→ TOO NARROW — black hammers
(Accept: any non-red hammer.)

**A saint is a holy person.** (pause; Signal)
→ GOOD

**A triangle is a red shape with three straight sides.** (pause; Signal)
→ TOO NARROW — blue triangles
(Accept: any non-red triangle.)

**(9), a dog is a black animal. Verdict and counterexample.**
→ TOO NARROW — white dogs

**(12), a dog is an animal. Verdict and counterexample.**
→ TOO WIDE — cats

**(9), which rule does "a dog is a black animal" break?**
→ Rule 1

**(12), which rule does "a dog is an animal" break?**
→ Rule 2

**(9), say Rule 1.**
→ A definition must include every instance of the thing defined.

**(12), say Rule 2.**
→ A definition must exclude everything that is not the thing defined.

**(12) only — both faults. A bird is a flying animal.**
→ TOO NARROW and TOO WIDE — penguins left out, bats let in
(Accept: ostriches / chickens for the miss; flies / mosquitoes / bats for the outsider. If she names only one fault: **There is another. What bird does not fly? What flying animal is not a bird?** Then have her give both.)

#### CORRECTION — 2A
Verdict without a counterexample: **Name the counterexample. What was left out, or what got in?** Repeat the same item.
TOO NARROW and TOO WIDE swapped: **Left out = too narrow = Rule 1. Let in = too wide = Rule 2.** Give the dog pair again, then the missed item.
Called a GOOD item TOO WIDE because a nearby kind exists: **Do those other kinds fit these words? A triangle is a shape with three straight sides. Does that let a square in?** → no **GOOD.**
Called "a dog is an animal" GOOD because dogs really are animals: **True of dogs, but too many outsiders get in. Cats are animals. TOO WIDE — cats.**
Gave a swarm instead of a test ("collies, beagles, and labs"): **That is yesterday's check. Today we test one answer. Listen again.** Repeat the definition.
Could not say which rule: point to the board. **Left out — Rule 1. Let in — Rule 2.** Then: **Which rule?**
Retest every corrected item in section 4. Always retest as verdict + named counterexample + rule number.

## 9. DRAFTER'S FLAGS

1. **Verdict without a counterexample is the most likely 9-year-old miss.** Fix already applied: every model, lead, test, and delayed item requires the named instance; the correction is "Name the counterexample," not a new lecture.

2. **TOO NARROW / TOO WIDE will swap.** Fix already applied: the first two models are a minimal pair on the same subject (*dog*); the correction recites "Left out = too narrow = Rule 1. Let in = too wide = Rule 2" and retests the pair together.

3. **"A dog is an animal" will be called GOOD** because the sentence is true of dogs. Fix already applied: the model and the correction say that truth about dogs is not enough if outsiders get in.

4. **SWARM and the new test will bleed into each other.** Fix already applied: guided practice interleaves a list-item and a one-line definition of the same X (*What is a dog? Collies...* vs *A dog is an animal that barks*); the correction names which job is on the table.

5. **"A dog is an animal that barks" is a useful messy item** (narrow for silent dogs, arguably wide for barking non-dogs). In guided practice, (9) may name one fault; (12) may name both. It is not the first GOOD, NARROW, or WIDE item, so the discrimination is already taught.

6. **The both-narrow-and-wide item is (12) only**, per the brief. *A bird is a flying animal* sits at the end of the test, labeled "(12) only," so (9) is not asked for two faults at once on day one of T6.

7. **The slave-boy scene is preview, not a second concept.** One act-three label check, then stop. Full treatment is Lesson 28.

8. **Meno's paradox is deeper only.** The 9-year-old firms the two rules and one SWARM item while (12) hears the one-line paradox and "inquire anyway, in order."

9. **Accepted counterexamples are any true instance or outsider**, not one official animal. A 9-year-old who says "brown dogs" instead of "white dogs" is correct. The script lists one sample after each arrow so the teacher is not left guessing, and names the acceptance rule in parentheses.
