# Ars Syllogistica

The Recitation Tablet (top left of the home screen, the same tablet as in Ars Grammatica and Ars Rhetorica) offers each of the four Logic as an Art study decks once that deck has been finished: What Logic Is, the First Act, the Second Act, and the Third Act. Once all four are finished, the whole of Logic as an Art can be recited as well. The student writes the doctrine from memory, then opens the deck's outline (the `recitation` field on the deck) and checks off the points covered. A deck without an outline does not appear. The home screen asks for a recitation again after 3, 7, and 30 days. The tablet does not grade the writing. The student's work is stored in this browser under `arsSyllogistica.progress.v1`. The code is `recitation.js` (shared with Ars Grammatica and Ars Rhetorica) and `recitation-adapter.js`.
